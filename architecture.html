Views & Routes

/ Dashboard.vue KPI cards, order health donut, inventory bar chart, backlog table, top products — 4 parallel API calls
/inventory Inventory.vue Searchable inventory table with client-side search on top of API-filtered results
/orders Orders.vue Status stat cards + order table with expandable items; all 4 filters active
/spending Spending.vue Revenue/Cost/Profit KPIs, monthly bar charts, category breakdown — merges static spending data with live order revenue
/demand Demand.vue Demand forecast table with trend badges (Increasing/Stable/Decreasing); no filters
/reports Reports.vue Quarterly performance table + monthly revenue trend chart; server-side aggregation, no filters

Data Flow

Filter change propagation
FilterBar.vue → useFilters singleton refs → watch() in every view → getCurrentFilters() → api.js URLSearchParams → FastAPI endpoint → apply_filters() → JSON response
Dashboard on load
Dashboard.vue onMounted → Promise.all(4 calls) → summary + orders + inventory + backlog → computed properties render charts
Spending view revenue calculation
Spending.vue → static spending endpoints (costs) + getOrders() (live revenue) → computed profit = revenue − costs

Composables — Singleton Global State

useFilters.js

Module-level refs shared across all components. Changing a dropdown in FilterBar triggers re-fetch in every open view simultaneously.

  • selectedPeriod → month
  • selectedLocation → warehouse
  • selectedCategory → category
  • selectedStatus → status
  • getCurrentFilters()
  • resetFilters()
  • hasActiveFilters (computed)

useI18n.js

Locale persisted to localStorage. Locale drives currency: ja → JPY at 150 USD/JPY (hardcoded).

  • t(key, params) — translate with fallback
  • setLocale()
  • translateProductName()
  • translateCustomerName()
  • translateWarehouse()

useAuth.js

Mock authentication. Always authenticated. User identity is locale-aware (John Doe / 田中 太郎).

  • currentUser (computed)
  • isAuthenticated → true
  • logout() → alert only
  • getInitials()
